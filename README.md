# React Native Learning Project 📱

Это мой учебный проект по React Native на базе Expo.

## О проекте

В этом репозитории я изучаю:

- React Native
- Expo
- React Navigation
- Работа с компонентами
- Hooks
- API
- Стилизация интерфейсов
- File-based routing

Каждый коммит в этом репозитории — отдельное занятие или этап обучения.

---

## Как скачать проект

### 1. Клонировать репозиторий

```bash
git clone https://github.com/AdiletZalgaraev/react-native-app.git
```

### 2. Перейти в папку проекта

```bash
cd react-native-app
```

### 3. Установить зависимости

```bash
npm install
```

### 4. Запустить проект

```bash
npx expo start
```

---

## Как работать с проектом

Основная папка проекта:

```bash
/app
```

Там находятся экраны и логика приложения.
